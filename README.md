# 교회 행사 구슬 추첨 — 방송 화면 업데이트

## 적용

먼저 제공된 `Supabase-방송화면수정.sql` 전체를 기존 프로젝트 SQL Editor에서 실행하세요. 행사 삭제·이름표 섞기·방송 대기 동기화 추가 설정을 모두 포함하며, 실행만으로 기존 행사를 삭제하지 않습니다. 최초 설정 SQL을 다시 실행하지 마세요.

그다음 이 폴더 안의 모든 파일을 GitHub 저장소 루트에 업로드하여 같은 이름의 파일을 교체합니다. ZIP 자체나 바깥 폴더를 올리는 것이 아닙니다. Pages main / (root) 설정은 유지합니다. 진행 중 추첨은 마무리하거나 취소한 뒤 업데이트하고, 배포 후 진행자·방송 화면을 모두 새로 여세요.

## 변경 내용

- 접수 중: 왼쪽 참가 QR, 오른쪽 구슬과 원본 미니맵. 새 참가자 등록과 제외가 대기 중 구슬에 자동 반영됩니다.
- 접수 마감: QR 영역이 사라지고 맵이 화면 전체 너비로 표시됩니다. 접수를 다시 열면 QR이 다시 나타납니다.
- 맵 전체 / 구슬 크게 버튼으로 대기 화면 보기를 전환할 수 있습니다. 큰 행사 제목과 하단 브랜드 문구는 방송에서 제거했으며, 저작권은 정보 아이콘으로 확인할 수 있습니다.
- 이름표 섞기를 누르기 전에도 맵/구슬이 보입니다. 섞은 뒤 참가자가 추가돼도 기존 구슬이 사라지지 않습니다. 시작 전에는 다시 섞어 최신 명단을 확정합니다.
- 추첨 진행 중에는 현재 회차 명단을 고정합니다. 새 참가자는 다음 회차 대상입니다.
- 기존 행사 삭제, QR 크게 보기, 회차별 추첨 방식 및 당첨자 제외도 포함합니다.

실시간 변경은 Supabase Realtime 통지를 받아 갱신하며, 통지가 끊기면 5초 간격 조회로 보완합니다. QR은 현재 사이트 주소를 사용하므로 배포된 사이트에서 생성된 QR을 사용하세요.

## 검증 및 소스

자동 검사 36개, TypeScript 검사, 배포 빌드 통과. 로컬 격리 환경에서 참가 등록 후 구슬 자동 추가, QR 표시/마감 전환을 검증했습니다. 실제 Supabase와 GitHub 적용은 별도입니다. 테스트 화면의 QR은 현장 접수용이 아닙니다.

`source.zip`은 수정된 전체 개발 소스입니다. 압축을 풀면 CLOUD-README.md와 모든 SQL 마이그레이션을 확인할 수 있습니다. 브라우저용 공개 Supabase URL/publishable key가 배포 JS에 포함되지만 DB 비밀번호, service_role/secret key, .env.local은 포함하지 않습니다.
